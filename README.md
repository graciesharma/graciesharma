## Hi, I'm Gracie

Full-stack developer based in Nepal. I've been at **Renegade Insurance** since January 2023 — three years as SDE 1, and SDE 2 since April 2026. Java on the backend, React and Next.js on the front.

Most of my work there is on an insurance marketplace that connects agents with carriers, wholesalers and MGAs — including the carrier appetite search that lets agents filter markets by state and product type, which is the part that decides how fast a risk gets placed. Before the marketplace I worked on the directory platform that came first, matching insurance buyers with local agents and agencies.

Outside work I build and ship sites for people in Nepal — schools, artists, small businesses. These are usually Next.js on Vercel with Supabase or Postgres behind them, and a CMS wired in so the owner can publish new work without going through me. Recent ones include a live wedding painter's portfolio and booking site, and a school site covering admissions, events and enquiries.

When I want a break from work code I build small tools in Vue and put them up on Vercel — a GitHub profile analyzer, a screen time calculator, a safe-migration resource site for Nepal.
